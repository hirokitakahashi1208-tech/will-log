# Will Log

やる気が出ない時期の人のための、「できたこと」を静かに残す記録アプリ。

**デモ:[https://will-log.web.app](https://will-log.web.app)** (スマホでも開けます)

## 背景
一般的なToDoアプリは、未完了の表示や連続日数で「できなかった日」を可視化する。うつ病や不登校で回復途中の人にとっては、それが自分を責める材料になり、アプリを消す原因になる。

想定ユーザー
- 中村 遥(20歳・休学中):主治医に「小さいことからでいい」と言われたが、何をどう続ければいいか分からない。
- 木村 真一(38歳・フリースクールのスタッフ):子どもを傷つけず、生活リズムを取り戻すきっかけを渡したい。

## 設計で決めたこと
| 決めたこと | 理由 |
|---|---|
| 記録が途切れた日は自動で「おやすみの日」 | 空白を「失敗」として表示しない |
| 「休むと決めた?」に答えるとポイント多め | 休むことを自分で選んだ行動として認める |
| ポイントは減らない・比較しない・連続日数を出さない | 途切れた瞬間に価値がゼロになる仕組みを避ける |
| 14日以上空いたら「おかえりなさい」と相談先 | 戻ってきたこと自体を肯定しつつ、支援への道をそっと残す |
| 吐き出しモードの文字は保存しない | 誰にも見られないと確信できる場所を用意する |
| 匿名ログイン | 名前やメールアドレスを預からずに使える |

## 技術構成
- React + TypeScript + Vite
- Tailwind CSS
- Firebase(Authentication:匿名 / Firestore / Hosting)
- UIプロトタイプ:Figma Make

データ構造
```
users/{uid}             bits, buffer, lastOpenedDate, lastLoggedDate, restCheckedThrough
users/{uid}/days/{日付}  logs
```
記録がない日はデータを作らず、画面側で「おやすみの日」と判定する。セキュリティルールで本人以外の読み書きをすべて拒否している。

## 動かし方
```
npm install
cp .env.example .env.local   # Firebaseの設定値を書き込む
npm run dev
```
